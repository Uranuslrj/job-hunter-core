# Boss 直聘自动投递系统

一套帮你把「筛选岗位、打分、写打招呼话术」这些求职体力活自动化的工具。它只帮你准备好一切，**发出去这一下永远留给你自己**。

## 这是什么

求职最累的不是投简历，而是：

- 每天刷几十上百个岗位，判断哪个值得投
- 针对每个岗位写不一样的招呼语
- 担心写的话术太模板、太舔、太假

这个系统把这些都自动化了：

| 功能 | 说明 |
|---|---|
| 岗位筛选 | 按你配置的关键词、城市、薪资自动筛，强度硬门槛（大小周/996 一票否决） |
| 四维打分 | 把「值不值得投」拆成成长空间/行业赛道/岗位匹配/薪酬 4 个维度量化打分 |
| 招呼语生成 | 六段固定框架，模型只选编号不写字，防编造 |
| 隐私脱敏 | 发给模型前自动打码姓名/电话/学校 |
| 台账对账 | 记录投了谁、回了谁，可查可复盘 |

## Features

| 特性 | 描述 |
|---|---|
| 防编造 | 模型只在你写好的「证据库」里选，不自己编数字 |
| 防舔话术 | 六段框架固定「理性判断」句式，杜绝"我很想去贵司" |
| 隐私硬脱敏 | 代码层打码，不依赖"让模型别说" |
| 六道发送检查 | 防张冠李戴、防重复投、防发错人 |
| 全部可配置 | 岗位、薪资、话术、隐私词全在 yaml 里，改配置不改代码 |
| 打分可调权重 | 四维权重（成长/赛道/匹配/薪酬）可自己改，符合自己的求职阶段 |

## 安装

```bash
git clone <你的仓库地址>
cd <项目目录>
python -m venv .venv
.venv\Scripts\activate        # Windows；macOS/Linux 用 source .venv/bin/activate
pip install -r requirements.txt
```

## 快速开始

只需 3 步，30 秒跑通：

```bash
# 1. 复制配置模板，填成你自己的
cp config/target_roles.example.yaml config/target_roles.yaml
cp config/greeting_spec.example.yaml config/greeting_spec.yaml
cp config/privacy.example.yaml config/privacy.yaml
cp config/model.example.yaml config/model.yaml

# 2. 填好上面 4 个文件里的 {{占位符}}（学校/岗位/薪资/你的API key 等）

# 3. 试跑（先演练，不真发）
python boss_skill/daily.py --dry --limit 3
```

每个 `.example.yaml` 模板文件里都有逐字段的填写注释，照着填即可。

## 配置说明

所有「跟你个人有关」的内容都在 `config/` 下 4 个文件里，每个都有 `.example.yaml` 模板。填的时候：

- **只改 `{{占位符}}`**，其余是通用逻辑不用动
- 能力可以写，**经历和数据不能编**
- 动机写"我认为这行业有前景"，别写"我真的很想去"

## 开源边界：骨架完整，护城河自己填

这个仓库开源的是**完整可跑的骨架**，不是"复制即用"的成品。填完 `{{占位符}}` 你就能跑通全流程，但决定结果的三样东西，模板里是空的，需要你自己填：

| 已开源（完整） | 需你自己填（护城河） |
|---|---|
| 代码框架、运行参数 | 你的档案数据（招呼话术、能力证据、经历） |
| 四维打分逻辑、强度硬门槛 | 你的打分权重、岗位族、求职策略 |
| 限速节奏、六道防错、风控分档、判重规则 | 你真实跑出来的评测数据（回复率、拦截数、回归通过率） |

**举个例子**：限速"每条间隔 12–35 秒"这类**运行参数**是开源的、你直接能用；但"风控词为什么要分两档、什么场景会误判"这类**踩坑经验**，散落在项目留痕里，模板填不出来。

一句话：**这套工具能帮你把重复劳动做完，但"填什么内容、怎么判断哪个岗位值得投"，是你自己的事——这也是它刻意留给你的价值。**

## 常见问题

**Q：会封号吗？**
有风险。平台禁止自动化，本工具不绕过风控、不破解验证码，但风险始终存在。请控制投递量、留人工闸门，并自行承担后果。

**Q：能全自动投递吗？**
技术上能，但强烈不建议。发出去不可逆，建议关键动作留给你自己确认。

**Q：我的信息会泄露吗？**
发给模型的请求会自动打码（姓名/电话/学校/公司换成占位符）。你自己的配置文件请用 `.gitignore` 挡在本地，别提交。
